# 🛠️ 故障排查与排坑自愈手册 (Troubleshooting)

本文档归纳了在硬件连接、固件烧录、网络注册及上位机运行过程中最常见的技术问题与直接解决方案。

---

## 1. 硬件连接与系统识别问题

### Q1: 模组插上电脑 USB，Windows“设备管理器”完全没有任何新端口弹出？
* **原因 A：使用了仅充电的两芯线**。部分手机或充电宝配送的线缆只有 VBUS 和 GND 两根电源线，缺少 D+ / D- 数据传输线。  
  👉 **解决**：换用支持高速数据传输的全功能 Type-C 数据线。
* **原因 B：一代开发板处于待机关机状态**。如果是 `Air780E / Air780EC`（`EVB_Air780X_V1.5`）评估板，出厂默认通电不启动。  
  👉 **解决**：**按住板上的 `S2`（POW 键）约 2 秒钟**，直到红色的电源指示灯常亮；或者按规范将 S2 按键短接接地。
* **原因 C：电脑尚未安装移芯驱动**。  
  👉 **解决**：下载并安装合宙官方提供的 **移芯通用 CDC 虚拟串口驱动**。安装后正常会识别出 3 个端口（包含 `19D1:0001` 特征）。

## 2. 烧录与固件死锁问题 (最常见痛点)

### Q2: 模组插上 SIM 卡后，USB 端口频繁断开重连，Luatools 提示 `[WinError 22] 设备不识别此命令`？
* **直接根因**：**Air780EPM 错刷了 `109` 固件！**  
  `LuatOS-SoC_V2050_Air780EPM_109.soc` 是合宙专为随身 WiFi 虚拟网卡剪裁的定制底包，**官方移除了 `sms` 短信驱动**。模组插卡入网瞬间调用短信服务，当场触发空指针异常导致看门狗循环复位死机。
* **解决办法**：
  1. 拔掉 Type-C 数据线；
  2. **按住板上的 `S1`（BOOT）键不放**，重新插上电脑 USB，强制进入出厂光刻 BootROM；
  3. 打开 Luatools，底层 Core 重新选择标准版 **`LuatOS-SoC_V2050_Air780EPM_103.soc`**；
  4. 点击【下载底层和脚本】重新刷入，开机即可彻底恢复。

### Q3: 烧录时提示“底层core文件不存在”或无法启动烧录？
* **原因**：Luatools 的 `.ini` 文件编码必须是 Windows 原生 `ANSI (GB18030)`。如果第三方编辑器误以 UTF-8 覆盖保存，会导致中文目录解析失败。  
  👉 **解决**：直接使用本项目 `tools/Luatools/project/` 下已配置妥当的现成工程。

## 3. 蜂窝网络与短信问题

### Q3: 信号强度显示 `99`，状态提示“搜网注册中...”，长时间无信号？
* **排查 1：天线未接牢或未安装**。4G 模组必须外接 4G 胶棒天线或 IPEX 贴片天线。
* **排查 2：电信卡插在了一代 EC618 板子上**。一代芯片（Air780E / 780EC / 700E）硬件缺少 IMS 协议栈，无法在电信 4G 搜网注册和接收短信。电信卡请务必使用 **Air780EPV** 或 **Air780EPM**。
* **排查 3：SIM 卡欠费或接触不良**。重新插拔 SIM 卡（金属接触面朝向板卡规范方向），并确认卡片已实名激活。

## 4. 上位机与 Web 控制台问题

### Q4: 双击 `Air780EPV-Gateway.exe` 闪退，或浏览器打不开 `http://127.0.0.1:17801`？
* **原因**：本地 `17801`（Web 控制台）或 `17800`（Hub 中枢）端口被其他后台进程占用。
* **排查与解决**：
  在 Windows PowerShell 中执行命令排查占用：
  ```powershell
  netstat -ano | findstr "17801"
  ```
  若有其他残留进程，在任务管理器中结束对应 PID，重新双击打开 Exe 即可。

### Q5: 收到短信但是没有自动复制到 Windows 剪贴板？
* **排查**：在 Web 管理控制台右上角点击设置抽屉，确认开启了【动态验证码自动复制到剪贴板】开关；若开启仍未复制，检查当前短信内容是否属于纯广告/通知类短信（算法会自动过滤无验证码内容的普通短信以防污染剪贴板）。
