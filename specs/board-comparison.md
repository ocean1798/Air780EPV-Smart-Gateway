## 二、 核心差异深入解析

### 1. Air700E vs Air780E：极致体积与频段的取舍
- **相同点**：两者主芯片完全相同（都是移芯 EC618），AT 指令集与 LuatOS 脚本完全通用。
- **Air700E 的定位**：
  - **极致小体积**：去掉了电信和联通所需的 FDD 射频滤波器和双工器，因此模块尺寸被压缩至 **10.5 × 13.5 mm**，厚度仅 1.7mm。
  - **专供场景**：超薄智能工卡、学生证、超薄定位器、水表/燃气表。
  - **代价**：**彻底丧失电信和联通网络支持，只能插中国移动卡**。
- **Air780E 的定位**：
  - 拥有完整的 FDD+TDD 射频外围，三网通流量，是合宙最普及的主力标准模块。

### 2. Air780E (780EC) vs Air780EPV / Air780EHV：电信与 VoLTE 的技术边界
- **为什么 780E / 780EC 不能收电信短信？**
  - 中国电信 4G 架构下，由于历史上 2G/3G CDMA 已被彻底拆网清频，短信传输**强制依赖 IMS / VoLTE 通道 (SMS over IMS)**。
  - 780E / 780EC（EC618 芯片）固件缺少 VoLTE 与 IMS 协议栈，因此即使插上电信卡能上网，基站也不会下发短信，**导致收不到任何验证码**。
- **为什么 Air780EPV 是经典短信转发神板？其后续迭代如何？**
  - 型号末尾的 **`V`** 代表 **Voice / VoLTE**。
  - 采用升级版 **移芯 EC718P-V** 芯片，原生集成了完整的 VoLTE / IMS 协议栈与硬件 Audio Codec 音频编解码。
  - **大满贯支持**：不仅支持移动、联通，还支持**电信**以及**中国广电**的短信收发，同时支持打电话、接听电话与 0 话费秒挂拦截。
  - **退市与迭代事实**：因 LuatOS 协议栈膨胀导致 Flash 空间告急，合宙官方在 `V1002` 之后停止为 EPV 发行公共固件并停止官方售卖。官方现役正统平替型号为 **`Air780EHV`**（8MB Flash + 8MB RAM，带内置 Audio Codec）。

## 三、 合宙 780 家族双字母与多字母后缀命名法则

合宙 780 系列（标准 16×18mm 尺寸）命名采用 **“平台代号 + 硬件规格 + 功能特化”** 的组合搭积木规则：

```text
Air780E + 【第 1 个后缀字母：硬件/内存档次】 + 【第 2 个后缀字母：核心功能用途】
```

### 3.1 核心字母字典

1. **第 1 位（或核心硬件档次）**：
   - **`P`**（Plain / Popular）：**4MB Flash + 4MB RAM**（入门实用级，4M 内存）；
   - **`H`**（High-spec）：**8MB Flash + 8MB RAM**（高配旗舰级，8M 内存）；
   - **`G`**（GNSS）：表示定位优先系列（如 GP、GH、GG）。
2. **第 2 位（或核心功能特化）**：
   - **`M`**（Memory / OpenCPU）：**纯数据/短信基础款**（不带语音）；
   - **`V`**（Voice）：**语音通话款**（内置硬件 Audio Codec + VoLTE 栈）；
   - **`T`**（Terminal / AT）：**纯 AT 指令款**（仅响应串口 AT，不能编写运行 Lua 脚本）；
   - **`G`**（G-Sensor）：**震动/重力加速度传感器**；
   - **`U` / `N`**（Universal / Network）：**海外频段款**（欧版/美版）；
   - **`R`**（RNDIS）：**USB 上网卡款**（原生默认锁定网卡模式）。

### 3.2 官方现役在售主力型号全景拆解

| 双字母后缀 | 完整型号 | 规格配置 | 核心功能与特性 | 适用业务场景 |
| :---: | :--- | :--- | :--- | :--- |
| **`PM`** | `Air780EPM` | 4M Flash + 4M RAM | 纯数传/短信款，全网通（含电信短信），**无 VoLTE** | 极致性价比纯短信转发、物联网传感器上报 |
| **`HM`** | `Air780EHM` | 8M Flash + 8M RAM | 大内存纯数传款，**无 VoLTE** | 挂载 SPI 屏幕、摄像头、复杂本地协议 |
| **`HV`** | `Air780EHV` | 8M Flash + 8M RAM + Audio Codec | **语音旗舰款**，支持 VoLTE、TTS 语音播报、通话呼叫 | **短信转发 + 0话费电话暗号秒挂（EPV正统接班人）** |
| **`HT`** | `Air780EHT` | 8M 平台 | **纯 AT 指令款**（不可烧录 Lua 业务代码） | 专供外挂 STM32 / ESP32 等单片机做 4G 通信外设 |
| **`GP`** | `Air780EGP` | 4M 平台 + 北斗/GPS | 卫星定位入门款 | 基础车载/防丢定位器 |
| **`GH`** | `Air780EGH` | 8M 平台 + 北斗/GPS | 卫星定位大内存款 | 复杂轨迹运算、带屏定位终端 |
| **`GG`** | `Air780EGG` | 8M 平台 + 北斗/GPS + G-Sensor | 定位 + 重力传感器款 | 动静自适应检测、车辆震动报警、静止深度休眠 |
| **`HU`** | `Air780EHU` | 8M 平台 + 海外频段 | 欧亚等海外 4G 频段款 | 外贸出海设备 |

### 3.3 早期与历史型号速查
- **`Air780E / EC`**：移芯 EC618 平台第一代，`C` 代表 China / Cost-down 纯国内频段优化版；
- **`Air780EP`**：移芯 EC718P 第一代，4M 内存纯数传版；
- **`Air780EPV`**：移芯 EC718P-V 第一代带语音版（已断货退市）；
- **`Air780EG`**：EC618 + Air510U 卫星定位第一代。

## 四、 运营商信令机制与定位能力事实

### 4.1 为什么没有 VoLTE 就“完全收不到电话信号”？
- **被动拦截原理**：
  - 在 LTE 纯 4G 网络中，VoLTE 是电话呼叫的**唯一信令通道（SIP INVITE）**。
  - 对于没有 VoLTE 协议栈的模组（如 `Air780EPM`、`Air780E`），运营商核心网在交换机侧检测到终端未注册 IMS 语音域，**直接在机房拦截呼叫并向主叫播报“无法接通”**。
  - 基站**完全不会向模组空中发射任何呼叫寻呼信号**，模组底层 0 事件、0 日志，根本不知道有来电。因此**凡需使用“来电暗号拦截秒挂”功能，必须选带 `V`（Air780EPV / Air780EHV）的型号**。

### 4.2 GNSS 卫星定位 vs 基站/WiFi 嗅探定位
- **GNSS（GPS/北斗）**：
  - 只有型号带 **`G`**（如 `Air780EGH`）的模组才板载卫星射频芯片，并配有独立的 GPS 天线接口；
  - 属于室外米级高精定位，但功耗大、必须能“看见天空”，在室内无法搜星。
- **无 GNSS 模组（如 Air780EPV / Air780EPM）的定位能力**：
  - **4G 基站定位（LBS）**：读取基站 MCC/MNC/TAC/CellID，精度约 500米~2公里，0 额外耗电，地下室可用；
  - **WiFi Scan 嗅探定位**：利用 2.4G 接收机扫描周边路由器 MAC 匹配云端，室内精度可达 10~50 米，无需连接 WiFi。
  - 作为随身短信网关，基站 LBS 与 WiFi 嗅探定位已完全满足城市级归属地呈现需求。

### 4.3 境外卡（如英国 giffgaff）中国漫游资费红线
- **短信接收**：全球 **永久免费（0 话费）**；
- **短信发送**：中国漫游 **30p / 条**（约 2.7 元人民币），不可使用英国本土短码（如 43430）；
- **蜂窝流量**：中国漫游按天价充值扣费 **20p / MB**（折合约 **1.8 元 / MB，1GB 约 1800 元**），**必须保持网关数据与 RNDIS 开关严格关闭**；
- **保号规则**：**180 天内必须产生一次付费消费**（推荐每 5 个月在控制台向国内号码发送 1 条短信，消耗 30p 即可将卡片有效期再续命半年）。

## 五、 硬件连接与系统调试避坑总结

1. **上电开机机制**：
   - 插入 USB 数据线后，开发板通常**默认处于关机状态**（仅电源指示灯 PWR 亮，模组未开机，无 USB 信号）。
   - **必须长按板上的 `POW / 电源键` 约 1.5 ~ 2 秒后松开**，NET 网络灯闪烁才代表模组成功开机；
   - 或按住 `BOOT` 键再按一下 `RESET` 键进入下载刷机模式。
2. **数据线假连接问题**：
   - 普通手机充电线内部缺少 D+/D- 差分信号线，插入后板子虽通电但电脑完全不会有 USB 提示音，必须选用**标准全功能数据线**。
3. **驱动与免驱**：
   - 在 Windows 10 / 11 上采用标准 **USB CDC-ACM 协议**，系统免驱直接识别出 3 个 COM 端口（AT 控制口、调试日志口、底层日志口）。
4. **Air780EPV 官方固件宏配置与能力边界**：
   - 当前官方为 Air780EPV 提供的主力底包为 `LuatOS-SoC_V2001_EC718PV_CLOUD.soc`。
   - **已开启核心宏**：`LUAT_USE_VOLTE`（高清通话）、`LUAT_USE_TTS_16K`（16K离线语音合成）、`LUAT_USE_INTER_AMR`（语音编解码）、`LUAT_USE_HTTPSRV`（板载Web/HTTP服务）、`LUAT_USE_SMS`（短信）与 `LUAT_USE_FOTA`。
   - **未开启宏**：未编译 `LUAT_USE_NETDRV`，因此调用 `mobile.config(mobile.CONF_USB_ETHERNET)` 会返回 `false`（无法直接作为 USB RNDIS 共享上网卡使用；若需 RNDIS 上网，需更换 ER/标准网卡版固件或自编固件）。
5. **V2001 固件兼容性避坑（`hmeta.chip()` 移除）**：
   - 在旧版开源脚本（如早期的转发库）中，`model.lua` 常调用 `hmeta.chip()` 获取芯片型号。在 V2001 固件中此接口已被移除，调用会导致 `attempt to call a nil value (field 'chip')` 开机死循环。
   - **修复范例**：使用 `(hmeta.chip and hmeta.chip() or "EC718PV")` 增加防崩容错保护。
6. **电脑流量保护（RNDIS 网卡）**：
   - 开发板内置 RNDIS 虚拟网卡，但 Windows 会将其路由跃点（Metric）自动设为较高值（如 35），电脑网络流量优先走本地宽带/WiFi（Metric 20/30），**调试时不会偷跑手机卡流量**。
