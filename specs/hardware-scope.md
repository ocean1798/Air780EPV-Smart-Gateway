# 合宙 780 系列模组开发：方向与范围

## 已确认目标与边界

本项目用于沉淀合宙 4G 蜂窝模组（重点覆盖 Air780E、Air780EPV 及关联的 Air700E 等 EC618/EC718 平台）的硬件规格、接口引脚、固件资产、通信协议与开发资料，并作为后续基于这些板卡进行功能开发（如短信转发、VoLTE 通话、RNDIS 网卡、MQTT/HTTP 物联网上报等）的统一工作区。

### 覆盖硬件对象
1. **Air780EPV（当前主测板）**：
   - 芯片平台：移芯 EC718P-V（Cortex-M4F 架构）。
   - 核心能力：4G Cat.1 bis 全网通、原生支持 VoLTE 语音通话、四网通短信（全网支持电信 SMS over IMS / VoLTE）、USB CDC 虚拟串口与 RNDIS 网卡。
   - 现存设备基线：固件 `AirM2M_780EPV_V1003_LTE_QAT`，已验证联通 4G 注册与蜂窝网络激活。
2. **Air780E / Core-Air780E（备选 3 块）**：
   - 芯片平台：移芯 EC618。
   - 核心能力：4G Cat.1 bis 全网通流量、支持移动与联通短信（不支持电信短信），低功耗长连接。
3. **Air700E（关联小封装板）**：
   - 芯片平台：移芯 EC618。
   - 核心能力：中国移动 TDD-LTE 专属超薄极小封装模组。

### 事实与产物边界
- 硬件规格、网络实测指标、AT 与 LuatOS 开发规范写入 `specs/`。
- 单次功能研发（如上位机短信监听工具、LuatOS 固件烧录与配置、Web 转发网关等）通过 `changes/<动作>-<对象>/` 推进。
- 业务代码与工程资产置于本 Project 独立目录下维护，不污染工作区根目录。
